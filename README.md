A chess engine in under 4 KB of Python: alpha-beta search with quiescence, piece-square tables and a transposition table, to a fixed node budget. It plays the house gauntlet over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
